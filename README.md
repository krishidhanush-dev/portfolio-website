# Responsive Portfolio Website

A responsive personal portfolio website built to showcase my skills, projects, and learning journey as an aspiring Python Full Stack Developer.

## Features
- Semantic HTML5 structure
- Responsive design for mobile and desktop
- Flexbox and CSS Grid layouts
- Home, About, Skills, Projects, and Contact sections
- Project cards with GitHub links
- Hover effects and smooth transitions
- Contact form UI (submission feature coming soon)

## Technologies Used
- HTML5
- CSS3
- Flexbox & CSS Grid
- Media Queries
- Git & GitHub
- GitHub Pages
